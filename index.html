⚙️ Quản Trị, Kết Nối Supabase & Triển Khai

Được thiết kế tối ưu cho Windows 10 Super Lite: Bạn có thể làm mọi thao tác ngay trên trình duyệt web mà không cần cài phần mềm nặng!

🔌 1. Kết nối máy chủ Supabase

✅ Đã kết nối Online

Dán Project URL và Anon Public Key từ trang quản lý Supabase của bạn vào bên dưới. ⚠️ CẢNH BÁO BẢO MẬT: Tuyệt đối KHÔNG dán `service_role` (secret key) hoặc mật khẩu cơ sở dữ liệu vào đây!

🔐 2. Tài khoản Thành viên & Quản trị

Khách chưa đăng nhập chỉ được xem các nội dung công khai. Hãy đăng nhập hoặc đăng ký tài khoản thành viên lớp 11T2 để tải ảnh, tạo sự kiện và viết lưu bút.

Đang đăng nhập với tài khoản:

🛡️ 3. Quản lý Quyền Thành Viên & Danh Sách Email Lớp (Dành cho Admin)

Chỉ Quản trị viên (`admin`) mới có thể thay đổi quyền trên PostgreSQL. Nếu email bạn học nằm trong bảng `allowed_emails`, khi đăng ký sẽ tự động được cấp quyền `member`.

Họ tên / Email Quyền hiện tại Ngày tham gia Thao tác cấp quyền
Hãy đăng nhập bằng tài khoản Quản trị viên (Admin) để xem và duyệt danh sách tài khoản.

💾 4. Sao lưu Dữ liệu & Quyền Riêng Tư

📦 Xuất bản sao lưu Metadata (.JSON)

Tải về toàn bộ dữ liệu văn bản: Danh sách Album, Sự kiện, Đường dẫn ảnh + Chú thích, Hồ sơ thành viên và Lời lưu bút dưới dạng file .json.

Lưu ý quan trọng: File .json chứa toàn bộ thông tin và đường link ảnh, nhưng các file ảnh gốc nằm trong Supabase Storage (bucket: class-memories) cần được tải về riêng từ bảng điều khiển Supabase Storage nếu bạn muốn lưu trữ ngoại tuyến vào USB/Google Drive.

🔄 Phục hồi Metadata từ file Sao lưu (.JSON)

Nếu cần khôi phục lại các Album, Sự kiện, Thành viên hoặc Lưu bút từ file sao lưu trước đó lên Supabase (Dành cho Quản trị viên).

📘 5. Hướng dẫn Cài đặt Supabase + Đưa lên Vercel (Dành cho Windows 10 Super Lite)

Bước 1: Tạo Dự Án Supabase & Chạy File SQL

  1. Mở trình duyệt vào https://supabase.com → Đăng nhập bằng tài khoản GitHub hoặc Email.
  2. Bấm New Project → Đặt tên thanh-xuan-11t2 → Đặt mật khẩu Database (nhớ lưu lại mật khẩu này cho riêng bạn) → Chọn vùng Singapore (Southeast Asia) cho nhanh → Bấm Create new project.
  3. Chờ khoảng 1 phút để dự án khởi tạo xong. Nhìn thanh menu bên trái, bấm vào biểu tượng SQL Editor → Bấm New query.
  4. Bấm nút "📋 Sao chép toàn bộ mã SQL (schema.sql)" ở góc trên bên phải khung này, dán vào ô SQL Editor của Supabase rồi bấm nút Run (hoặc Ctrl + Enter).
  5. Khi hiện thông báo Success. No rows returned là toàn bộ bảng, 13 Album mặc định, Bucket ảnh class-memories và hàng rào bảo mật RLS đã được tạo xong!

Bước 2: Lấy URL, Anon Key & Cấp Quyền Admin Đầu Tiên

  1. Trong Supabase, vào Project Settings (biểu tượng bánh răng) → API.
  2. Copy Project URL và anon / public key dán vào mục "1. Kết nối máy chủ Supabase" ở ngay phía trên trang này rồi bấm Lưu & Kết nối.
  3. Ngay tại mục "2. Tài khoản Thành viên" ở trên, nhập Email + Mật khẩu của bạn và bấm Đăng ký tài khoản mới. (Nếu Supabase yêu cầu xác nhận email, bạn có thể vào Authentication → Providers → Email → Tắt Confirm email cho tiện cả lớp).
  4. Để tự phong mình làm Quản trị viên (Admin) đầu tiên: Vào lại SQL Editor của Supabase, chạy đúng 1 dòng lệnh sau (thay bằng email của bạn): UPDATE public.profiles SET role = 'admin' WHERE email = 'email-cua-ban@gmail.com';

Bước 3: Đưa Website Lên GitHub & Vercel Để Có Link Online Cho Cả Lớp

Vì bạn đang dùng Windows 10 Super Lite, bạn không cần cài đặt Node.js hay Git vào máy! Bạn chỉ cần làm trên trình duyệt web:

  1. Sau khi đã dán URL và Anon Key ở mục 1 phía trên, hãy bấm nút màu xanh lá "📦 Xuất file index.html đã gắn cấu hình cho cả lớp". Trình duyệt sẽ tải về file index.html đã được điền sẵn URL và Anon Key công khai của lớp bạn.
  2. Truy cập https://github.com → Đăng nhập → Bấm dấu + góc trên phải chọn New repository → Đặt tên thanh-xuan-11t2 → Bấm Create repository.
  3. Bấm vào dòng chữ uploading an existing file → Kéo file index.html (và các file schema.sql, README.md tải từ trang này) thả vào → Bấm nút xanh Commit changes.
  4. Truy cập https://vercel.com → Chọn Continue with GitHub → Bấm Add New... → Project → Chọn kho thanh-xuan-11t2 vừa tạo → Bấm Import → Bấm Deploy.
  5. Chỉ sau 20 giây, Vercel sẽ tặng bạn một đường link dạng https://thanh-xuan-11t2.vercel.app. Hãy gửi đường link này vào nhóm Zalo/Messenger của lớp 11T2 để cả lớp cùng vào xem và tải ảnh!
  6. Cách cập nhật sau này: Mỗi khi muốn sửa code, bạn chỉ cần upload đè file index.html mới lên GitHub, Vercel sẽ tự động cập nhật website sau 15 giây.
